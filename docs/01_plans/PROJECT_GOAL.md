# プロジェクト目標：究極の外乱耐性

二足歩行ロボット『旋風丸』プロジェクトの最優先目標は、**「外乱への圧倒的ロバスト性の獲得」**です。

## 核心的ビジョン
単に平地を歩くことではなく、**「動かしても倒れない機体」**の実現を追求します。

*   **能動的外乱回復**: 外部からの押しや衝突を瞬時に検知し、全身の20自由度を駆使して姿勢を立て直す。
*   **踏み出し制御**: 転倒の危機に際して、能動的に足を一歩踏み出し、支持基底面を拡張してバランスを維持する。
*   **不整地適応**: 予測不能な段差やスリップに対しても、AIがリアルタイムに環境を推定し、制御パラメータを最適化する。

## 学習・開発の指針
1.  **報酬関数**: 重心安定性 (`com_stab`) と姿勢回復速度 (`recovery`) に高い優先度を与える。
2.  **外乱カリキュラム**: 学習の初期段階から多様かつ強力な外乱（バースト・プッシュ）を印加する。
3.  **Sim-to-Real**: センサーノイズや通信遅延を徹底的にシミュレートし、実機の不完全な情報下でも倒れない「タフな知能」を育成する。
