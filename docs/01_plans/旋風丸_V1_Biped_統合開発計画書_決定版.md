# **20自由度二足歩行ロボット『旋風丸 V1 Biped』統合開発計画書 ＆ 仕様設計書（公式プロトコル準拠・最終決定版）**


---

## **1. プロジェクト基本方針 ＆ 開発ビジョン**

本設計書は、愛知工業大学チャレンジプロジェクト（学チャレ）における技術継承のスタートラインにして、初代の物理検証機である20自由度二足歩行ロボット**『旋風丸 V1 Biped』**の仕様書である。

「安価かつ調達が容易なシリアルサーボモータ」を全身に搭載し、上位のPC/ラズパイとMCUによる脳脊髄分離、足裏FSRセンサーの信号処理など、歩行ロボティクスに必要な「電装インフラ・古典ZMP/CoP重心制御・通信」を確実に実証することを目的とする。

特に、実機製作時にサーボの即全焼やラズパイの破損を招く**「電源電圧」「ロジックレベル」「通信ピンアサインの物理的衝突」「プロトコルチェックサム」**といった致命的なハードウェア地雷を100%回避し、ノイズ・波形歪み等の電気的問題をも実測妥当なレベルまで徹底的に抑え込む、電気科・機械科の知見を結集したバイブルとなる。

## **4. 電気・通信の最重要ハードウェア設計ルール**  
【V1 脳脊髄通信 ＆ LVCH16T245 ピン全二重割り当て図】

```
      [Raspberry Pi 5 (大脳 / 100Hz 推論)]        [Teensy 4.1 (脊髄 / 1kHz ハードリアルタイム)]  
       │                                         │
       │                                         ├─ [AE-LLCNV-LVCH16T245 双方向レベル変換]
       │                                         │   ├── Group 1 (Ch 1~8, DIR1=HIGH 固定 / A->B)
       │                                         │   │    ├─ UART1_TX (Pin 1) ─── サーボバス1 (右脚 6軸)
       │                                         │   │    ├─ UART2_TX (Pin 8) ─── サーボバス2 (左脚 6軸)
       │                                         │   │    ├─ UART4_TX (Pin 17) ── サーボバス3 (右腕 4軸)
       │   【脳脊髄通信 (100Hz)】                │   │    └─ UART5_TX (Pin 21) ── サーボバス4 (左腕 4軸)
       │                                         │   └── Group 2 (Ch 9~16, DIR2=LOW 固定 / B->A)
       │                                         │        ├─ UART1_RX (Pin 0) ─── サーボバス1 RX
       │                                         │        ├─ UART2_RX (Pin 7) ─── サーボバス2 RX
       │                                         │        ├─ UART4_RX (Pin 16) ── サーボバス3 RX
       │                                         │        └─ UART5_RX (Pin 20) ── サーボバス4 RX
       └───・USBシリアル（Type-A to Micro-B） ───┼─ SPI1 (Pin 26,27,11,12) ─ MCP3208 (← MCP6004 VDD=3.3V)  
                                                 └─ UART6 (Pin 24,25) ─ BNO055 IMU (115200bps)  
```
