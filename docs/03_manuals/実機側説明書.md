# 二足歩行ロボット『旋風丸』実機デプロイ ＆ 運用説明書（決定・全解決版）

本書は、Raspberry Pi 5 (大脳) ＋ Teensy 4.1 (脊髄) による脳脊髄分離アーキテクチャを用いた実機『旋風丸 V1 Biped』の運用・デプロイ手順書です。

---

## 1. システムアーキテクチャ ＆ 通信仕様

- **大脳 (Raspberry Pi 5, 16GB)**: 100Hz (10ms) で ONNX 推論、観測履歴構築、経路計画。
- **脊髄 (Teensy 4.1, 600MHz)**: 1kHz (1ms) で全ペリフェラル (4x BusLinker UARTs, SPI1 MCP3208, UART6 BNO055) の管理、1kHz E-stop 監視。
- **通信インターフェース**: `real/real_io.py` 内の `TeensySpineIO` (USB Serial 100Hz テレメトリ/指令パケット)
  - **30ms タイムアウト自律 E-stop**: Pi 5 がフリーズした際、30ms 以内に Teensy 4.1 が全サーボのトルクを切り安全停止。

---

## 2. 段階的検証ロードマップ (Phase 0 〜 Phase 3)

### 🔹 Phase 0: 文書・コード整合性確定 (完了)
- 3S LiPo (11.1V) / 5V5A UBEC への電源統一。
- 20自由度（脚12軸 ＋ 腕8軸、頭部なし）の `JOINT_NAMES` 照合。
- MCP3208 SPI1 (`/dev/spidev1.0`) 配線。

### 🔹 Phase 0.5: SIL (Software-in-the-Loop) ダミー検証
- 実サーボに接続する前に `real_io.py` のダミーモードで `main_loop` 全体を走行させ、推論次元数・関節マップ・ログの正常性を検証。

### 🔹 Phase 1: 50Hz テザー安定化電源テスト
- 大型直流安定化電源から 11.1V を給電し、転倒防止吊り下げハーネスの元で 50Hz 低速歩行テスト。

### 🔹 Phase 2: 70-80Hz オンボードバッテリー試走
- 3S LiPo バッテリーおよび 5V/5A UBEC を搭載し、無制限動作テスト。

### 🔹 Phase 3: 100Hz フルスピード運用
- PREEMPT_RT リアルタイムカーネルおよび CPU コア分離 (Core 3 隔離) を適用した100Hz完全リアルタイム駆動。
