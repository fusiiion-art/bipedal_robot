# 二足歩行ロボット深層強化学習における報酬関数設計・詳細仕様書（改訂版）

本仕様書は、二足歩行ロボット『旋風丸 (Senpumaru)』の深層強化学習（DRL / Brax PPO / MuJoCo MJX）における報酬関数・安全制約・安定性指標の厳密な数理定義を記述したドキュメントです。

---

## 1. 概要と最優先目標

本報酬系の目的は、単なる歩行動作の獲得にとどまらず、強烈な外乱（押出し・蹴り）を受けても即座に理論的最適着地点（Capture Point）へ足を一歩踏み出し、自律的に姿勢を復帰させる**「究極の外乱耐性の獲得」**です。

---

## 2. 報酬関数コンポーネント

### 2.1 PBRS (Potential-Based Reward Shaping)
Ng et al. (1999) の理論に基づき、割引率 $\gamma = 0.99$ とポテンシャル関数 $\Phi(s)$ による報酬成形を適用：

$$r_{pbrs} = \gamma \Phi(s_{t+1}) - \Phi(s_t)$$
$$\Phi(s) = w_{up}\cdot \exp(-5.0(1 - \cos\theta \cos\phi)) + w_{tgt}\cdot \exp(-2.0\|p_{xy}\|^2 - \psi^2)\cdot \lambda_{phase}(s)$$

### 2.2 動的位相移行係数 $\lambda_{phase}(s)$
通常歩行時 ($\lambda_{phase} \to 1.0$) と外乱リカバリー時 ($\lambda_{phase} \to 0.0$) を滑らかに分離：

$$z(s) = 5.0\sqrt{\theta^2+\phi^2} + 0.5\|\omega_{xy}\| + 1.5\|v_{xy}\| + 2.0\cdot\mathbb{1}[\text{was\_disturbed}]$$
$$\lambda_{phase}(s) = \exp\left(-10.0\cdot\max(0,\, z(s) - 0.3)\right)$$

### 2.3 2段階プログレッシブ Capture Point 報酬
Capture Point ($p_{cp} = p_{com} + v_{com}/\omega_0$) と遊脚目標位置の距離 $d$ に対する2段階評価：

$$r_{cp} = 0.6 \exp(-2.5 d) + 0.4 \exp(-15.0 d^2)$$

### 2.4 ZMP (Zero Moment Point) サポート多角形マージン
LIPM加速度 $a_{com}$ および足裏荷重分布から正確な ZMP を算出し、支持領域半径 $r_{support}$ からの距離マージンを計算：

$$\text{ZMP}_{xy} = p_{com,xy} - \frac{a_{com,xy}\cdot h}{a_{com,z}+g}$$
$$\text{zmp\_margin} = \text{clip}\left(1.0 - \frac{\text{dist}(\text{ZMP}, \text{support})}{r_{support}},\, 0.0,\, 1.0\right)$$

### 2.5 Log-Barrier（対数バリア）ソフト制約
- **最低高度バリア** ($h < 0.35\text{m}$ で対数急増)
- **関節トルクバリア** (定格85%超過で対数急増)
